# Poker Session Manager ♠️

A clean and efficient Flutter application designed to manage poker sessions, track bank balances, and monitor cash-out times with a real-time countdown.

## 🚀 Features

* **Active Balances Dashboard:** View all currently open sessions/bank balances in a clean list format.
* **Real-Time Countdown:** Live timer showing exactly how much time remains until the designated cash-out time.
* **Create New Sessions:** Easily add new groups with a name, buy-in amount, and target date/time.
* **Validation:** Smart form validation to ensure correct data entry and future dates for cash-outs.
* **Status Indicators:** Visual cues for active timers vs. expired sessions.

## 🛠 Getting Started

To run this project locally, follow these steps:

### Prerequisites
* [Flutter SDK](https://docs.flutter.dev/get-started/install) installed.
* An IDE (VS Code or Android Studio).

### Installation

1.  **Clone the repository:**
    ```bash
    git clone [https://github.com/YOUR_USERNAME/poker_app.git](https://github.com/YOUR_USERNAME/poker_app.git)
    cd poker_app
    ```

2.  **Install dependencies:**
    ```bash
    flutter pub get
    ```

3.  **Run the app:**
    ```bash
    flutter run
    ```
